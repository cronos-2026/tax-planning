後台登入紀錄

成功登入後會全自動記錄：登入帳號、登入時間、裝置識別、公開 IP、瀏覽器／作業系統資訊；不需另外設定電腦名稱。若部分裝置資訊不可取得，系統只記錄可取得的資訊，至少保留登入時間、帳號與公開 IP（若 IP 查詢未被網路阻擋）。 本機會立即保存；因 GitHub Pages 是純前端網站，尚未輸入 GitHub Token 前無法寫入中央記錄檔。 當 Token 測試成功、同步前台或按下「同步登入紀錄」時，會把待同步紀錄寫入 admin-login-log.json。

全自動辨識： 登入頁不需要填寫電腦名稱。系統會自動建立此瀏覽器的穩定裝置識別，並記錄可取得的瀏覽器／作業系統資訊與公開 IP。 一般瀏覽器無法讀取 Windows／macOS 真正的主機名稱，因此「裝置識別」是系統自動建立的識別碼。 若安全環境限制部分裝置資訊，系統會自動降級，只保存能取得的資料；若公開 IP 查詢也被網路或防火牆阻擋，IP 會顯示「無法取得」。
